# Aaria Moments — Downloads

Professional wedding-photo curation software: removes duplicates and
out-of-focus shots, recognises the bride, groom and VIPs, and builds a
story-aware album under your photo budget.

This repo hosts installer downloads only. Source code is private.

## Latest release

See the [Releases](../../releases) page for the current Mac (.dmg) and
Windows (portable .zip) downloads.

## Mac install

1. Download `AariaMoments-Mac.dmg`
2. Open it, drag **Aaria Moments** into Applications
3. First launch: right-click the app → **Open** → **Open** (one-time —
   the app isn't notarized by Apple, so Gatekeeper will warn once)

## Windows install

1. Download `AariaMoments-Windows-Portable.zip`
2. Unzip the whole folder anywhere
3. Double-click **Start Aaria Moments.vbs**

No installation, no Python, no internet connection needed to run.
